# Quilt Documentation

Quilt lets metaprograms in any language generate and manipulate code in any other language using five Unicode arrow glyphs.

The current release is **v0.6.0** — see [Release Notes](release-notes.md).

A `.quilt` file is ordinary source code with Quilt brackets spliced in. Running `quilt expand` strips the brackets and writes plain source — no special build system required.

```rust
// squares.py.rs.quilt  —  a Rust program that generates Python
let squares: Vec<u64> = (1..=5).map(|n| n * n).collect();

let program = python↖
    def main():
        squares = ↙squares.↑↘
        print(squares)

    main()
↗;

println!("{}", program.coparse());
```

```python
# generated squares.py
def main():
    squares = [1, 4, 9, 16, 25]
    print(squares)

main()
```

The five operators — quote `↖↗`, unquote `↙↘`, lift `↑`, reduce `↓`, emit `←` — compose across any combination of supported languages. See [Concepts](concepts.md) for a full walkthrough.

### Repository layout

```
quilt/
├── quilt/              # Core library + CLI (crate `quiltlang`); vendored grammars in quilt/grammars/
├── quilt-lsp/          # Language Server
├── quilt-python/       # PyO3 bindings (Python runtime, PyPI `quilt-python`)
├── quilt-wasm/         # wasm-bindgen runtime for TypeScript / the browser (npm `quilt-wasm`)
├── quilt-expand-wasm/  # The expander as a WASI command, for the in-browser playground
├── quilt-conformance/  # Capability-claim harness behind the Support Matrix
├── conformance/        # Per-language claim specs (conformance/spec/<lang>.toml)
├── fuzz/               # cargo-fuzz targets (separate workspace)
├── bin/                # Helper scripts, fronted by bin/main
├── nix/                # Dev-shell definition (loaded by direnv via .envrc)
├── tools/quilt/        # VS Code extension
├── docs/wiki/          # This wiki (docs/design/ holds design notes)
└── examples/           # Annotated .quilt examples, incl. examples/notebook/
```
