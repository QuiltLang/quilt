Every cell below is declared in `conformance/spec/<lang>.toml` and, where the harness can reach it, verified against the implementation by `cargo test -p quilt-conformance`. A claim that stops being true fails CI. See [issue #144](https://github.com/QuiltLang/quilt/issues/144).

## Key

| | Meaning |
|---|---|
| ✅ `supported` | Works, and a probe proves it |
| 🟡 `partial` | Works within a stated limit; the glyph links to the tracking issue |
| ⬜ `unsupported` | Deliberately unsupported; the probe asserts a clean error |
| 🔵 `planned` | Intended and tracked by an issue; not yet implemented |

A cell marked with a trailing `*` is **declaration-only**: it is recorded in the spec but no tier of the harness verifies it yet.
